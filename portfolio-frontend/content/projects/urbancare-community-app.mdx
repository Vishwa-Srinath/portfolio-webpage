## Project context

UrbanCare is a modeled community infrastructure platform for reporting road damage, waste-management problems, streetlight failures, and other public issues. Citizens submit reports through a mobile experience while authorities coordinate resolution from a centralized dashboard.

## Design work

- Applied object-oriented analysis and design principles to model a scalable system
- Designed the mobile reporting and authority-facing web dashboard flows
- Defined notification and issue-resolution workflows
- Used UML to document the system's structure and interactions

## Technical scope

The project focuses on Java and object-oriented programming, UML, OOAD, Android application design, web dashboard architecture, and cloud-backend concepts.
